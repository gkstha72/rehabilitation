정확한 변환을 위해 SCIM 채점 시 다음을 꼼꼼히 체크해주세요:
· 식사: 쇠젓가락 / 에디슨 젓가락 / 포크 중 실제 사용 도구
· 목욕: 목욕의자·휠체어·손잡이 등 특별한 세팅 사용 여부
· 옷입기: 단추 / 지퍼 / 신발끈 조작 가능 여부
· 몸단장: Universal cuff / Adaptive comb 사용 여부
· 배뇨: 유치 도뇨관 / 외부 배뇨 도구(edi) 사용 여부
· 배변: 좌약 사용 여부
· 용변처리: Portable bidet / Toilet aids / 안전장치 사용 여부
· 계단: 난간 잡고 수행 / 난간 없이 수행
· 이동: '완전 독립 (감독 불필요)' 명시 체크 시에만 만점 반영

※ 자동 변환의 한계:
· 배변·배뇨는 SCIM(실금 중시)과 MBI(조절 가능성) 관점 차이로 오차 발생 가능
· 항목별 세부 상황(발톱 정리, 특정 부위 등)은 SCIM에 없어 반영 불가
· 자동 변환 후 [MBI 탭에 반영] 클릭 → MBI 탭에서 세부 조정 필수
