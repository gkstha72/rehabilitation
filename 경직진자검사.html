1. 처리하는 정보

사용자가 선택적으로 입력한 비식별 검사코드, 측정일, 환측 정보와 기기 자이로스코프 측정값 및 분석 결과를 처리합니다. 성명과 병원등록번호는 입력하지 마십시오.

2. 처리 목적

무릎 진자검사의 측정, 결과 분석, 재측정 판단 및 사용자가 요청한 보고서 생성에만 사용합니다.

3. 처리·전송 방식

  • 측정과 분석은 사용 중인 기기 안에서만 수행됩니다.
  • 앱은 검사정보와 측정값을 외부 서버, 광고업체 또는 분석업체로 전송하지 않습니다.
  • 앱은 검사 세션을 별도의 계정이나 클라우드 데이터베이스에 저장하지 않습니다.

4. 보유와 삭제

검사정보와 측정값은 현재 검사 세션 동안에만 기기 메모리에서 사용됩니다. ‘검사 종료 및 데이터 삭제’를 누르면 입력값, 측정값, 분석결과와 앱의 임시 보고서 파일을 삭제합니다.

5. 보고서 저장·공유

사용자가 사진, 파일, 메시지 또는 다른 앱으로 내보낸 보고서는 앱의 관리 범위를 벗어납니다. 저장·공유 전에 대상자 식별 가능성과 보관 위치, iCloud 등 외부 동기화 여부를 확인하십시오.

6. 사용자 주의사항

  • 개인을 직접 식별할 수 없는 검사코드만 사용하십시오.
  • 임상 사용 시 소속기관의 개인정보 보호절차와 적법한 처리 근거를 확인하십시오.
  • 식별 가능한 보고서를 개인 사진 보관함이나 승인되지 않은 서비스에 저장하지 마십시오.
